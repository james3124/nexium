PROJECT NEXIUM

Independent Rust-Powered Headless Browser Engine

1. PROJECT VISION

Build NEXIUM, an independent, high-performance browser engine written primarily in Rust.

NEXIUM is designed to operate as a headless browser while providing the capabilities and behavior of a traditional headful desktop browser.

Unlike conventional headless browser solutions, NEXIUM must not depend on Chromium, Google Chrome, Firefox, WebKit, Playwright, Puppeteer, or other existing complete browser engines.

We are developing our own browser infrastructure, including:

- HTML parsing engine.
- DOM engine.
- CSS parsing and styling engine.
- Layout engine.
- Rendering engine.
- JavaScript execution environment.
- Networking engine.
- Browser storage system.
- Browser interaction engine.
- Navigation and tab management.
- Visual perception system.
- AI agent integration.

The browser must operate without opening an actual graphical browser window.

AI agents should be able to interact with websites as if they were operating a normal desktop browser.

The primary objective is to create an independent browser infrastructure that can be controlled by AI agents and external applications.

- Manage multiple tabs.
- Process animations.
- Handle scrolling.

Operating Modes

Implement two modes.

Mode A: Headless

The browser operates completely in the background.

No visible browser window is created.

Mode B: Remote Visualization

Allow external applications to receive rendered screenshots or streamed frames.

This does not require opening a browser window on the host machine.

The visualization system should be optional and separate from the browser engine.
